# LINE SLASH 一閃

線を引いて敵を斬る、1対1の3Dリアルタイムバトル(WebGL / three.js)。Android・iPhone・iPad のブラウザ向け PWA。

- ターン制ではない。勇者も敵も、いつでも線を引いて攻撃できる
- 引ける線は 1 本だけ。線を引き終わり、その線に沿った攻撃が終わって元の位置に戻るまで、次の線は引けない(敵も同じ)
- 自分: 画面に線を引くと、勇者がその線の通りに駆け抜けて斬る。光る弱点を通るとクリティカル
- 敵: 赤い線を引き、その線に沿って突進してくる。勇者が自分の線で移動中なら回避でき、タップでガードもできる
- 敵の HP を 0 にすると勝ち、勇者の HP が 0 になると負け。勝つと次の敵との戦いが自動で始まり、負けるまで続く
- 敵は 竜 → 岩の巨人 → 死神 の順に登場し、一巡すると色違いの強化版になる
- 勇者は 20000 ポリゴン、敵は各 30000 ポリゴン(コードで生成。`npm run count` で検証)

## 開発

```sh
npm install
npm run dev     # 開発サーバー
npm test        # ビルド + Playwright テスト(ローカルの Google Chrome を使用)
npm run icons   # PWA アイコンの再生成
```

## 公開

`main` ブランチに push すると GitHub Actions(`.github/workflows/deploy.yml`)が GitHub Pages に公開する。

## アップデート

起動時・10分ごと・アプリが前面に戻った時に新バージョンを確認する。新バージョンはバックグラウンドで取得され、
ゲーム中には適用されず、タイトル画面またはゲームオーバー画面でのみ適用(リロード)される。
